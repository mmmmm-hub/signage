# バス発車案内 (signage)

科技大キャンパス周辺のバス停に設置する、駅の発車標のようなバス接近案内をブラウザだけで表示する静的ページです。ビルド不要・サーバー不要で、`index.html` を開くだけで動作します。

## 特徴

- 現在時刻をもとに、選択した方向(大学行き／千歳・長都方面行き)の次のバスを自動で計算して表示
- 直通／空港経由／長都(おさつ)方面を色分け表示
- 到着予定時刻(千歳駅・長都駅・本部棟など)も表示
- 画面サイズに合わせて表示件数を自動調整(縦画面・横画面どちらも対応)
- 特定の経由の便しか停まらないバス停では、その旨を自動で注意表示
- 右下のボタンから全画面表示(PC/Android)。iPhoneはホーム画面に追加すると全画面風に起動
- 学休期ダイヤ(夏季・冬季)にも対応

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面本体(HTML/CSS/JS を1ファイルにまとめたもの) |
| `bus-logic.js` | 発車時刻の計算ロジック(運行日判定・到着時刻算出など) |
| `timetable-data.js` | バス停・時刻表データ |
| `manifest.json` | スマホのホーム画面に追加したときの表示設定 |
| `convert.cjs` | 元データ(`../vivibus/src/data/timetable.ts`)から `timetable-data.js` を生成するスクリプト |

## 使い方

1. `index.html` をブラウザで開く(ローカルファイルでもそのまま動作します)
2. 右下の ⚙ から、表示するバス停・方向(行き/帰り)・表示件数の上限を設定
3. 設定は端末に保存されるので、次回起動時も同じ設定で表示されます

URL パラメータで直接指定することもできます。

```
index.html?stop=univ_main&dir=to_city&limit=8
```

| パラメータ | 説明 | 例 |
|---|---|---|
| `stop` | 表示するバス停ID | `univ_main`, `chitose_st` など |
| `dir` | 方向 | `to_univ`(行き) / `to_city`(帰り) |
| `limit` | 表示件数の上限(省略時は画面サイズに自動調整) | `8` |

## 時刻表データの更新

時刻表を更新する場合は、`../vivibus/src/data/timetable.ts` (本体アプリ側のデータ) を編集したうえで、このフォルダで以下を実行してください。

```bash
node convert.cjs
```

`timetable-data.js` が最新の内容で上書きされます。

## キオスク運用について

- 長時間表示し続ける前提のため、6時間ごとに自動リロードします
- タブレットやスマホをスタンドに固定して常時表示する使い方を想定しています
