# 写真えらび (photo-sorter)

観光地などで連続して撮った「ほぼ同じ写真」を自動でまとめ、その中からベストショットを選ぶ静的ページです。
ビルド不要・サーバー不要で、`index.html` をブラウザで開くだけで動きます。

写真の読み込み・解析・書き出しはすべてブラウザの中だけで行われ、**画像はどこにも送信されません。**

## できること

1. 選んだ写真を撮影日時順に並べ、「撮影時刻が近い」かつ「見た目が似ている」写真を1つのまとまりにする
2. まとまりごとにピント・明るさ・解像度を採点して、ベストショットを1枚(設定で最大3枚)選ぶ
3. 選んだ結果を確認・手直しして、次のいずれかで書き出す
   - **残す写真をZIP保存** … 残す写真だけを ZIP にまとめてダウンロード
   - **削除候補リスト** … 減らす写真のファイル名一覧をテキストで保存
   - **不要な写真を退避フォルダへ** … 元フォルダから `退避_YYYYMMDD` へ移動(下記の対応環境のみ)

## 使い方

1. `photo-sorter/index.html` をブラウザで開く
2. 「写真を選ぶ」または「フォルダを選ぶ」、もしくは画面にドラッグ＆ドロップ
3. 解析が終わると、似た写真のまとまりごとに一覧が出る
   - ★ が自動で選んだベストショット。緑枠が「残す」、暗くなっているものが「減らす」
   - 写真をタップ/クリックすると残す・減らすを切り替えられる
   - 右上の ⤢ で原寸表示。縮小画像だと分かりにくいピントはここで確認できる
4. 画面下部のボタンで書き出す

### 設定

| 項目 | 内容 |
|---|---|
| 同じ場面とみなす撮影間隔 | この時間より離れて撮られた写真は、見た目が似ていても別のまとまりにする(既定: 2分以内) |
| 似ていると判定する基準 | ゆるくするとまとまりが大きくなり、減らせる枚数が増える。厳しくすると取りこぼしが減る |
| 選ぶときの重視点 | ピント重視か、明るさ・写り重視か |
| 1グループで残す枚数 | 1〜3枚。迷うときは2枚にしておくと安全 |

設定を変えると自動で選び直します(手動で切り替えた内容はリセットされます)。

## 判定のしくみ

| 目的 | 方法 |
|---|---|
| 撮影日時 | JPEG の EXIF `DateTimeOriginal` を読む。無ければファイルの更新日時を使う |
| 似ている写真の検出 | 9×8 に縮小して横隣の明暗を比べる **dHash**(64bit)のハミング距離。明るさ全体の違いに強い |
| 別の被写体との区別 | 4×4 ブロックの平均 RGB。全体の明るさで正規化してあるので、露出違いの連写は分かれない |
| ピント | 縮小画像に **ラプラシアンフィルタ**をかけたときの分散。ぼけているほどエッジが消えて小さくなる |
| 明るさ・写り | 輝度のコントラスト・白飛び黒つぶれの割合・平均輝度から算出 |

ピントの絶対値は被写体によって大きく変わります(空だけの写真は常に低く出る)が、
このツールは**同じ場面のまとまりの中だけで相対比較**するため、被写体による差が打ち消されます。

解析は長辺 384px に縮小してから行うため、数百枚あっても端末のメモリを圧迫しません。

## 対応環境と制限

- 対応形式: JPEG / PNG / WebP など、ブラウザがデコードできる画像
- **iPhone の HEIC**: Safari では読めますが、Windows/Android の Chrome では読めないことがあります。
  読めなかったファイルは画面下部に一覧表示されます。iPhone から取り出すときに JPEG 変換しておくと確実です
- **「不要な写真を退避フォルダへ」** はファイルを書き換えるため、File System Access API に対応した
  パソコンの Chrome / Edge でのみ使えます。それ以外のブラウザでは ZIP 保存と削除候補リストを使ってください
- ブラウザからスマホのカメラロールを直接消すことはできません。
  スマホの写真を整理する場合は、いったんパソコンにコピーしてから使うのが確実です
- ZIP 保存は無圧縮(store 方式)で、合計 3GB 未満を想定しています

## 退避フォルダについて

「不要な写真を退避フォルダへ」は**削除ではなく移動**です。元のフォルダに `退避_YYYYMMDD` を作り、
そこへ移します。中身を確認してから、自分でフォルダごと捨ててください。

移動に対応していないブラウザではコピー後にサイズを検証し、一致した場合のみ元ファイルを削除します。
検証に失敗した場合は元ファイルを残すので、写真が消えることはありません。
